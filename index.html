A aprendizagem de HTML permitiu conhecer a estrutura de uma página web e compreender como organizar diferentes conteúdos. Durante as aulas, aprendi a utilizar títulos, parágrafos, imagens e ligações para apresentar informações de forma clara.

Com CSS, aprendi a melhorar a aparência das páginas através de cores, tamanhos de letra, margens e bordas. O uso conjunto de HTML e CSS ajuda a criar páginas mais organizadas e agradáveis para os utilizadores.
